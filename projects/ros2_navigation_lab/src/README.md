# ROS2 소스 패키지

이 폴더에는 `ros2_navigation_lab` workspace에서 사용하는 ROS2 source package가 들어 있습니다.

현재 포함된 패키지는 다음과 같습니다.

```text
lee_robot_description
```

`lee_robot_description`에는 Gazebo simulation model, launch 파일, SLAM/Nav2 설정, map, RViz 설정, 그리고 선택적으로 실행할 수 있는 LiDAR wall-following 예제 node가 포함되어 있습니다.
