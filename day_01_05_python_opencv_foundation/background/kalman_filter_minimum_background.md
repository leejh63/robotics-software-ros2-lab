# Background: Kalman Filter 최소 배경지식

## 1. 핵심 구조

Kalman Filter는 두 가지 정보를 섞는다.

```text
predict
  이전 상태와 운동 모델로 현재 상태를 예측한다.

update
  센서 관측값으로 예측을 보정한다.
```

---

## 2. YOLO 중심점 추적 예시

상태:

```text
x = [cx, vx, cy, vy]^T
```

관측:

```text
z = [cx, cy]^T
```

YOLO는 위치만 주고 속도는 주지 않는다. 속도는 필터가 내부적으로 추정한다.

---

## 3. P, Q, R

| 기호 | 의미 |
|---|---|
| P | 현재 추정 상태의 불확실성 |
| Q | motion model의 불확실성 |
| R | 센서 관측값의 불확실성 |

```text
R이 크다 -> YOLO bbox를 덜 믿는다.
Q가 크다 -> 움직임 예측을 덜 믿는다.
P가 크다 -> 현재 상태 추정이 불확실하다.
```

---

## 4. NIS

NIS는 관측 오차가 예상한 불확실성에 비해 큰지 보는 값이다.

```text
평균 NIS가 측정 차원과 비슷하다
  -> R 설정이 어느 정도 일관적일 가능성

평균 NIS가 너무 크다
  -> R을 너무 작게 잡았을 가능성

평균 NIS가 너무 작다
  -> R을 너무 크게 잡았을 가능성
```
